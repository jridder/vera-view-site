Vera View

Vera View is a fast, lightweight viewer for diagrams and drawings saved in the Microsoft® Visio® file formats (.vsdx, .vsdm, .vstx and .vstm). Open a file and see it as it was drawn: no account, no subscription and nothing to edit by accident.

Features

  • Opens large diagrams with tens of thousands of shapes in seconds
  • Smooth pan, zoom and scroll bars
  • Find text on every page, with highlighted matches
  • Multiple pages, background pages, stencil shapes, connectors and pictures
  • Read-only: Vera View never changes your files
  • Works offline and collects no data

Download

Free, for Windows, Linux and macOS. Get the newest version from the latest release:

  • Windows 10/11: VeraView-Setup-version.exe. Installs for your user account, no admin rights needed. A Microsoft Store version is on its way.
  • Linux: the .AppImage runs on most distributions (make it executable, then run it); Debian and Ubuntu users can install the .deb.
  • macOS 11 or later (Apple Silicon and Intel): open the .dmg and drag Vera View to Applications.

The downloads aren't code-signed yet, so the first time you run Vera View, Windows may show "Windows protected your PC" (choose More info, then Run anyway), and macOS may block it (right-click the app and choose Open).
