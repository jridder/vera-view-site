Report a problem or ask a question

Open a support request on GitHub (free GitHub account required). Please include your Windows version, the Vera View version (shown in About), and what happened.

Support requests are public. If a drawing is confidential, describe the problem instead of attaching the file.

Common questions

Which files can Vera View open?
Drawings saved in the current Visio formats: .vsdx, .vsdm, .vstx and .vstm. Older .vsd files aren't supported; save them as .vsdx in Visio first.

Can I edit drawings?
No. Vera View is a viewer and never changes your files.

Some parts of my drawing look different.
Gradients, shadows, theme effects and EMF/WMF pictures aren't fully supported yet. Please report anything that looks wrong.
